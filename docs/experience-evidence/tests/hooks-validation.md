新增覆蓋：

- 同事不同帳號、中文／空白路徑、Windows 8.3 暫存路徑；拒絕跳出根目錄及重新導向。
- 同一事實跨兩筆記的部分更正遭拒，批次更正成功；保留同檔其他事實及舊正文。
- 合成 ANNA 職業矛盾、否定句不誤當肯定句、不同人物不混用、職業別名辨識。
- 格式偏好的值保留大小寫及空白，未知自由文字列為待語意核對，不宣稱全無矛盾。
- 兩程序用同 revision 寫入，一方成功、另一方被拒；重新合併後兩筆都保留。
- 交易在各 atomic_write 邊界中斷後重播；索引同步、不使用半完成記憶。
- 新對話、compact、同對話另一寫入者更新、全局／專案隔離、工作目錄改變。
- hook 阻擋已知錯誤路徑及直接 Write/Edit；一般工作檔案可照常操作。
- 保存後漏通知或連錯筆記時補救一次；封存通知須連到實際歷史檔；無變更不通知。
- 安裝保留其他 hooks 與權限、重複安裝不重複註冊、卸載保留記憶、損壞 JSON 先拒絕。
- 兩種乾淨 ZIP 解壓後工具可執行，公開包不含 `.git`、私人筆記或測試日誌。

隔離載入 project/local 設定，停用原生 auto-memory，避免另一記憶機制干擾。

| 情境 | 實際結果 |

| 第三輪更正標題為淺綠色 | 原筆記更新、索引同步、保留歷史，並通報 |
| 第四輪询問目前顏色 | 回答淺綠色，未輸出讀記憶的流程語言 |

不代表已替真實使用者全局安裝。有限樣本不能推論所有模型／版本成功率 100%。

## 2026-09-19 效能修補（fast-20260919）

使用者提供約 232 秒螢幕錄影；另核對該工作區對應的一輪 Claude 本機工具紀錄，
沒有把影片或私人對話發布。送出要求到最後回覆的紀錄相差 156.006 秒，11 次模型
回應、10 次工具呼叫（7 Bash、1 Read、2 Write），包括兩個失敗結果：

1. 全局 PreToolUse 把安裝位置 framework/SKILL.md 誤當平行記憶路徑，拒絕 Read。
2. 初次 apply 缺少 jason-facts，模型重新製作計畫再送一次。

加上查 --help、讀完整協議／runtime 文件、寫刪暫存計畫，形成不必要的模型往返。
原輪次約 65K token 的初始輸入包含宿主、工具與其他常駐內容，不能全部歸因記憶框架。
各模型回應的 usage 已按 message id 去重；累計 cache-read 不是唯一上下文長度，
也不能按未快取 token 單價計算費用。工具起訖含宿主排程及 hooks，非純 Python 執行時間。

### 修改與保留的保護

- 只允許讀取實際框架的協議／工具文件，其他錯誤記憶路徑仍拒絕。
- remember 一次產生 Markdown、日期及事實欄位，執行索引／健檢／讀回收據；
  同鍵同值只驗證，不同值拒絕快速覆寫，要求沿批次更正流程保留其他事實。
- apply 支援 stdin；完整快照可重用，日常不必再讀 SKILL.md 或執行額外健檢。
- 無收據的普通工具不再觸發整庫掃描。Stop 仍查整庫，假保存、缺通知與矛盾仍有保護。
- 正常交易只驗證一次，不重寫未變更筆記；中斷重播仍重新驗證，寫後仍讀回比對。
- runtime 輸出 UTF-8 JSON；已有收據及完整有效連結的通知不因措辭不同而重試。

PostToolUse，shell 無收據時仍有程序啟動成本。100 筆範例 context 的 JSON 字元數由
ASCII 逸出約 82,707 降為 UTF-8 文字約 44,511；字元數不是模型 token 數。
新增回歸涵蓋單次保存、重複免重寫、混合筆記拒絕盲改、全部同鍵筆記驗證、非法輸入、
stdin／ASCII 終端 UTF-8、無關筆記時間戳、路徑誤判、普通工具快返與 Stop 保護。

另以新版專案入口實跑三輪：remember 新增偏好、verify 再確認且原筆記修改時間
不變、apply 更正成先風險再結論與細節。三輪均有有效收據，最後仍只有同一則
有效筆記，保留原檔名及 created；不是靠新增矛盾筆記達到更正。
